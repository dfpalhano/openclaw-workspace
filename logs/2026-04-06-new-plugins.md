## 1. cc-godmode 🚀
**Type:** Multi-agent development workflow orchestrator
**Description:** Self-orchestrating multi-agent development workflows. You say WHAT, the AI decides HOW.
**Key Features:**
- 8 specialized agents (@researcher, @architect, @builder, @validator, @tester, @scribe, @github-manager, @api-guardian)
- Dual quality gates (parallel execution)
- Version-first approach
- MCP server integration (Playwright, GitHub, Lighthouse, A11y)
**Use Case:** Complex development projects requiring multiple specialized agents

## 2. god-mode 🔭
**Type:** Project oversight & monitoring
**Description:** AI agent coaching and project oversight system
**Key Features:**
- GitHub project monitoring (commits, PRs, issues)
- Weekly activity reports
- Multi-provider support (GitHub, GitLab, Azure DevOps)
- SQLite cache for performance
**Use Case:** Monitoring development projects across multiple repositories

## 3. capability-evolver 🧬
**Type:** Agent capability evolution system
**Description:** Evolutionary algorithm for agent capability improvement
**Key Features:**
- Genetic evolution of agent capabilities
- Memory graph for skill retention
- A2A (Agent-to-Agent) protocol
- Skill distiller and publisher
**Use Case:** Continuous improvement of agent capabilities through evolutionary algorithms

## 4. evolver 🔄
**Type:** Lightweight agent evolution
**Description:** Simplified version of capability-evolver
**Key Features:**
- Basic evolutionary patterns
- Skill analysis and promotion
- Event logging and analysis
**Use Case:** Agent self-improvement without complex genetic algorithms

## 5. self-improving-agent 🤖
**Type:** Self-improvement framework
**Description:** Framework for agents to improve their own skills
**Key Features:**
- Error detection and learning
- Skill template generation
- OpenClaw integration hooks
- Feature request tracking
**Use Case:** Agents that can diagnose and fix their own limitations

## 6. agentmail 📧
**Type:** Email automation for agents
**Description:** Email sending and inbox management for AI agents
**Key Features:**
- Email sending via SMTP/API
- Inbox checking
- Webhook setup for email notifications
- Template-based email generation
**Use Case:** Agent communication via email (notifications, alerts, responses)

## 7. feishu-evolver-wrapper 📱
**Type:** Feishu (Lark) integration for evolver
**Description:** Wrapper to connect evolver system with Feishu messaging
**Key Features:**
- Feishu card message sending
- Health check monitoring
- Dashboard visualization
- Weekly insight reports
**Use Case:** Delivering agent evolution insights via Feishu/Lark

## 8. obsidian-direct 📝
**Type:** Obsidian vault direct access
**Description:** Direct CLI access to Obsidian vaults
**Key Features:**
- Obsidian CLI interface
- Vault search and navigation
- Note creation and editing
- Graph visualization access
**Use Case:** Managing Obsidian knowledge base from command line
