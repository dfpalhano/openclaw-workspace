## Agent Context Optimisation — Implemented 06 Mar 2026 ~14:20

### Problem
Spawning sub-agents costs 3,000–8,000 tokens just for context init.
Goal: reduce to ~800 tokens via caching + distillation + surgical briefing.

### What was built
- `agent-context/base-soul.md` — Minimal stable soul for all sub-agents (~190 tokens). Stable = prompt cache hits at ~10% cost after first call.
- `agent-context/distill.py` — Context distiller. Takes task + memory files → calls Gemini Flash → tight 400-word brief. Consumes cheap tokens upfront, saves expensive tokens on the capable model.
- `agent-context/brief-template.md` — Standard format for surgical handoffs. Task + inputs + distilled context only.
- `agent-context/spawn-log.jsonl` — Append-only log of every spawn: model, estimated tokens, task, files used.
- `agent-context/spawn.sh` — CLI wrapper: distil → build brief → log → output ready-to-spawn brief.

### How to use (Atlas internal)
1. Before `sessions_spawn`, call distill.py with the task + relevant files
2. Pass the output brief as `task=` in sessions_spawn, not the full context
3. Sub-agent reads base-soul.md (stable, cached) + brief only
4. All spawns auto-logged to spawn-log.jsonl

### Token economics (estimated)
| Approach | Init tokens |
|---|---|
| Full context dump | ~8,000 |
| Base soul only | ~190 |
| Base soul + distilled brief | ~800 |
| After prompt cache hit | ~80 |
