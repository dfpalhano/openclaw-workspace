## 📋 **PHASE 1 FORM PRIORITIZATION (Weeks 1-6)**

### **TIER 1: CRITICAL FOR VACANCY REDUCTION**
**These directly address the $90,000 vacancy problem**

#### **1. Registration/Application Form**
```
FREQUENCY: Daily (5-10/week)
IMPACT: High (directly affects vacancy duration)
COMPLEXITY: Medium
RISK: Medium (data validation needed)

CURRENT WORKFLOW:
1. Lead inquires via Flatmates/WhatsApp
2. Diego receives, sends registration link
3. Lead completes, returns to Diego
4. Diego reviews, approves
5. Diego sends next steps

NEW WORKFLOW (Mathis):
1. Lead inquires → Mathis receives
2. Mathis selects registration template
3. System auto-fills house/vacancy details
4. Mathis sends link, tracks completion
5. Completed form → Diego oversight queue
6. Diego reviews (30 sec), approves

TIME SAVINGS: 15 min/form × 7 forms/week = 1.75h/week Diego time
VACANCY IMPACT: Faster onboarding = reduced vacancy
```

#### **2. Bond Return Form**
```
FREQUENCY: Weekly (2-3/week)
IMPACT: High (affects move-out → move-in timeline)
COMPLEXITY: Low-Medium
RISK: Medium (financial calculations)

CURRENT WORKFLOW:
1. Occupant moves out, requests bond return
2. Diego calculates bond, creates form
3. Diego sends to occupant
4. Occupant completes, returns
5. Diego processes payment

NEW WORKFLOW (Mathis):
1. Occupant requests bond → Mathis receives
2. System auto-calculates bond (from MC data)
3. Mathis reviews, sends form
4. Occupant completes → Diego oversight queue
5. Diego approves payment

TIME SAVINGS: 20 min/form × 2.5 forms/week = 50 min/week
VACANCY IMPACT: Faster bond return = faster re-occupancy
```

#### **3. Room Inspection Form**
