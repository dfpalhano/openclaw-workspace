# Staff Dashboard Prototype

Mock-only prototype for the Mission Control staff operations layer.

## Safety
This prototype uses cloned/mock data only.
It does not write to live Mission Control data and does not send live WhatsApp messages.

## Files
- `index.html` — main prototype UI
- `styles.css` — prototype styling
- `app.js` — client-side logic
- `data/` — mock datasets used by the prototype

## How to open
Open `index.html` in a browser, or serve this folder locally with any static file server.

## Prototype scope
- vacancies
- under-notice rooms
- occupants
- leads / Flatmates pipeline
- house groups
- mock message preview/confirm flows
- mock activity feed

## Notes
This is a prototype only. It is designed to validate:
- staff access boundaries
- UI/UX for Mathis and Lenny
- inspection/vacancy workflow shape
- messaging guardrails
