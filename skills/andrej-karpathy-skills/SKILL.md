# Andrej Karpathy Skills

Use these guidelines when coding in OpenClaw:

- Think before coding, state assumptions, surface ambiguity
- Keep it simple, avoid speculative abstractions
- Make surgical changes only
- Work toward explicit, verifiable success criteria

## Practical rules

- Ask when the task is unclear
- Prefer the smallest change that solves the problem
- Do not refactor unrelated code
- Verify results before declaring success
