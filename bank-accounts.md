## Usage Guidelines

### When to Use Which Account
1. **SH1 (40 Rosa St, Spring Hill)** → Use SH1 dedicated account
2. **SH2 (36 Rosa St, Spring Hill)** → Use SH2 dedicated account  
3. **All other houses** → Use default (Diego personal) account

### House Codes & Corresponding Accounts
- **SH1**: 40 Rosa St, Spring Hill → SH1 account
- **SH2**: 36 Rosa St, Spring Hill → SH2 account
- **CO1, EB1, EB2, EB3, GS1, SB1, SH3, SP9, V5, WE1, WL3, WL4, BRIS1** → Default account

### Payment Reference Format
When instructing occupants to make payments, use:
```
Reference: [HouseCode] [Room] [Name]
Example: SH1 R3 John Smith
```

### Security Notes
- These details are for internal reference only
- Never share full account details in public communications
- Use only in occupancy offer cards and payment instructions
- Verify house code before providing payment details
